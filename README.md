# oldFunny iOS

A new Swift/UIKit oldFunny client in progress. The first unsigned ARM64 IPA is built; iPhone installation and runtime testing are pending.

[Download the first IPA artifact ZIP](https://github.com/sandrscore/oldFunny-iOS/actions/runs/39478438577/artifacts/12291131063) (extract the IPA for Zeus; expires October 27, 2026).

See [build instructions and verification](ios/README.md) and [feature status](ios/PORT_STATUS.md). Chats, Studio/publishing, push and other features remain unfinished. This is a native source port, not an APK binary conversion or a feature-complete release.
